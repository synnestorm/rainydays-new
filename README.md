# JavaScript Course Assignment: Rainydays

In this assignment I were to use my new skills in writing JavaScript, and create a interactive online store to display product from an API endpoint. I've used my existing cross course project as my starting point, and used the provided Noroff APIs.

## Description

This is Rainydays - an online store selling durable jackets for all kinds of weather. Whether you are going hiking, kayaking or skiing; rainydays jackets are designed for your everyday adventure.

- Products page with filtering
- View a single product with more details
- Add products to shopping cart
- Going through checkout process
- Confirmation screen after checking out

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- APIs

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone git@github.com:synnestorm/rainydays-new.git
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run start
```
